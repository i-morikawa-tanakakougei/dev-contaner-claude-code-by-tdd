TDD/DDD/レイヤードアーキテクチャプロジェクトの特定GitHubイシューについてアプリケーション層（ユースケース）を実装する。

## メタデータ
- **前提条件**: ドメイン層実装完了（06-implement-domain）
- **入力**: イシュー番号（必須）
- **出力**: 
  - アプリケーション層実装: `src/application/`
  - ユースケース、DTO、インターフェース
  - 更新された `docs/use_cases/issue-X-Y.json` メタデータ
- **依存関係**: ドメイン実装、テスト成功
- **実行タイミング**: ドメイン層実装後、インフラストラクチャ層実装前

## 実行例

### ✅ 成功例
```bash
$ /implement-usecase 15
🎯 Issues: #15 のユースケース層実装を開始します
✅ ドメイン層が正常に実装されています
🏗️ アプリケーションサービス実装中...
  ✅ ファイル作成: src/application/use_cases/authenticate_user.py
🎉 ユースケース層実装完了!
```

重要なポイント:
- ドメインオブジェクトを調整するユースケース作成
- アプリケーション関心事（トランザクション、認証）を処理
- 入力/出力のDTOを使用
- すべてのユーザー向け出力は日本語である必要があります

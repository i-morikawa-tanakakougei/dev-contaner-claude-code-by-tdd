## Common Errors and Solutions

### ❌ Error Case 1: Test results not found
**Cause**: Missing test execution results or incorrect result file location  
**Solution**: 
- Check test-results/ directory exists with recent results
- Verify you ran `/run-all-tests` successfully before this command
- Re-run `/run-all-tests` if results are missing

### ❌ Error Case 2: High test failure rate detected
**Cause**: Multiple test failures indicating code quality issues  
**Solution**: 
```bash
# Focus on critical test failures first
/review-test-results-enhanced --mode failure-analysis
# Address root causes before proceeding
```

### ❌ Error Case 3: Low test coverage detected
**Cause**: Insufficient test coverage below quality thresholds  
**Solution**: 
```bash
# Identify coverage gaps and create additional tests
/review-test-results-enhanced --mode coverage-analysis
# Use /create-tests to add missing test coverage
```

# TDD/DDD/Layered Architecture Commands - 統合版使用ガイド

## 🚀 **概要**

このガイドでは、安全性とエラーハンドリングを大幅に強化した**統合版 TDD/DDD/Layered Architecture カスタムコマンド**の使用方法について説明します。

## 🔧 **主な改善点**

### **✅ 解決された問題**

| **問題**              | **従来版**                                   | **統合版**                                        |
| --------------------- | -------------------------------------------- | ------------------------------------------------- |
| **Git 操作の失敗**    | `git checkout -b` でエラー時にリポジトリ破損 | `safe_create_or_switch_branch` で自動ロールバック |
| **メタデータ破損**    | `jq ... > file && mv` で競合状態発生         | `update_metadata_atomic` で原子性確保             |
| **GitHub API エラー** | `gh` コマンドでエラー時に処理停止            | `safe_gh_command` でリトライ・ログ記録            |
| **部分的失敗**        | 中間状態で停止、手動復旧必要                 | トランザクション機能で完全ロールバック            |
| **前提条件無視**      | コマンド順序を間違えても実行                 | `validate_command_prerequisites` で事前チェック   |

### **🆕 新機能**

1. **🔄 トランザクション管理**: 複数ステップ操作の原子性確保
2. **📊 包括的ログ記録**: 全操作の詳細ログとトレーサビリティ
3. **🛡️ アーキテクチャ検証**: DDD/Clean Architecture 違反の自動検出
4. **🔍 前提条件検証**: フェーズ依存関係の強制
5. **📈 GitHub API 最適化**: レート制限・エラー処理・リトライ機能

## 🛡️ **安全機能の詳細**

### **1. トランザクション管理**

```bash
# 自動的に実行される処理
begin_transaction "create_use_case_123"
  → add_rollback "git checkout main && git branch -D 'feature/branch'"
  → add_rollback "rm -f 'metadata.json'"
  → add_rollback "git reset --hard HEAD~1"
  → [操作実行]
  → commit_transaction()  # 成功時
  # または
  → execute_rollback()    # 失敗時
```

### **2. GitHub API 最適化**

```bash
# 自動リトライとエラーハンドリング
safe_gh_command "issue" "create" --title "..." --body "..."
  → 認証チェック
  → レート制限確認
  → 最大3回リトライ
  → エラーログ記録
  → 成功/失敗の明確な返り値
```

### **3. 原子的メタデータ更新**

```bash
# 競合状態を防ぐ安全な更新
update_metadata_atomic "metadata.json" '.phase = "completed"'
  → JSON構文チェック
  → 一時ファイル作成
  → 原子的置換
  → 整合性検証
  → バックアップ作成
```

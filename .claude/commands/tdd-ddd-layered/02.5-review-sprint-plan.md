## Common Errors and Solutions

### ❌ Error Case 1: Sprint planning documents not found
**Cause**: Sprint review attempted before sprint planning completion  
**Solution**: 
```bash
# Create sprint plan first
/sprint-planning <sprint-number>
# Then proceed with review
/review-sprint-plan <sprint-number>
```

### ❌ Error Case 2: Core scenarios misalignment
**Cause**: Sprint scenarios don't align with project vision and core scenarios  
**Solution**: 
- Review core scenarios in docs/use_cases/core/index.md
- Realign sprint planning with project priorities
- Update sprint plan to focus on core business value

### ❌ Error Case 3: Capacity overcommitment
**Cause**: Sprint planning includes too many scenarios for team capacity  
**Solution**: 
- Reduce sprint scope to realistic capacity
- Prioritize high-value core scenarios
- Move lower-priority items to future sprints

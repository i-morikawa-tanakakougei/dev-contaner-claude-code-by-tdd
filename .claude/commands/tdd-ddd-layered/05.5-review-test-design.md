## Common Errors and Solutions

### ❌ Error Case 1: Tests are passing (not RED phase)
**Cause**: Tests were created with accidental implementation or are testing existing code  
**Solution**: 
```bash
# Verify tests fail properly
uv run --frozen pytest tests/ -v
# If tests pass, fix test implementation
/create-tests <issue-number>  # Recreate proper failing tests
# Then re-review
/review-test-design <issue-number>
```

### ❌ Error Case 2: Test files not found
**Cause**: Test review attempted before test creation  
**Solution**: 
```bash
# Create tests first
/create-tests <issue-number>
# Then proceed with review
/review-test-design <issue-number>
```

### ❌ Error Case 3: Incomplete Given-When-Then coverage
**Cause**: Tests don't cover all scenarios from specifications  
**Solution**: 
- Analyze missing scenarios and add corresponding tests
- Update test implementation to cover all acceptance criteria
- Ensure business edge cases are properly tested

   ```bash
           echo "✅ Critical tasks確認完了"
       fi
       
       # Basic content verification (keeping existing checks)
       if ! grep -q "ステータス:" "$latest_report"; then
           verification_issues+=("レビューレポートにステータスが記載されていません")
       fi
       
       if ! grep -q "TDD REDフェーズ評価" "$latest_report"; then
           verification_issues+=("TDD REDフェーズ評価が不完全です")
       fi
       
       if ! grep -q "Given-When-Thenカバレッジ評価" "$latest_report"; then
           verification_issues+=("シナリオカバレッジ評価が不完全です")
       fi
   fi
   
   # Check metadata updates
   metadata_updated=0
   for issue_num in "${issue_numbers[@]}"; do
       metadata_file=$(find docs/use_cases -name "issue-${issue_num}-*.json" | head -1)
       if [[ -f "$metadata_file" ]] && grep -q "test_design_review" "$metadata_file"; then
           metadata_updated=$((metadata_updated + 1))
       fi
   done
   
   if [[ $metadata_updated -eq ${#issue_numbers[@]} ]]; then
       echo "  ✅ メタデータ更新: ${metadata_updated}/${#issue_numbers[@]} 完了"
   else
       verification_issues+=("メタデータ更新が不完全: ${metadata_updated}/${#issue_numbers[@]}")
   fi
   
   # Check agent exit code
   if [[ $agent_exit_code -ne 0 ]]; then
       verification_issues+=("エージェント実行エラー (終了コード: $agent_exit_code)")
   fi
   
   # ✨ Show comprehensive verification results
   show_verification_results "05.5-review-test-design"
   
   # Final decision based on verification results
   if [[ ${#verification_issues[@]} -eq 0 ]]; then
       echo "✅ エージェント結果検証完了"
   else
       echo "❌ エージェント結果検証で問題が発見されました:"
       printf '  - %s\n' "${verification_issues[@]}"
       echo ""
       echo "💡 問題解決のための推奨アクション:"
       echo "  1. テストファイルの再確認と必要に応じた修正"
       echo "  2. /create-tests ${issue_numbers[*]} でのテスト再作成検討"
       echo "  3. /review-test-design ${issue_numbers[*]} でのレビュー再実行"
       exit 1
   fi
   ```

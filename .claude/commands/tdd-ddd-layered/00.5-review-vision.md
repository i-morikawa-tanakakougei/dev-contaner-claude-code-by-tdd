## 🔍 **VISION REVIEW: ANALYSIS AND ALIGNMENT ONLY**

**⚠️ Important Notice:**
- **This step is VISION REVIEW ONLY** - Analyze and validate vision alignment with stakeholders
- **NO VISION CHANGES** - Focus on evaluation and stakeholder feedback collection  
- **Alignment analysis** - Review vision clarity, stakeholder understanding, and business goals
- **Generate review reports ONLY** - No vision document modifications

**Review Process:**
1. `00-create-vision` ← Project vision and core scenarios created
2. `00.5-review-vision` ← **【YOU ARE HERE】Vision validation and stakeholder alignment**
3. `01-init-project-structure` ← Project structure setup begins (if approved)
4. Alternative: Return to `00-create-vision` ← Revise vision (if alignment issues found)

**Critical Vision Validation Focus:**
- ✅ Stakeholder understanding and agreement on project goals
- ✅ Business value alignment and ROI clarity
- ✅ Scope and constraint validation
- ✅ Success criteria and acceptance definition

## 🎯 **LARGE-SCALE PROJECT SPECIFIC CONSIDERATIONS**

**When to Use This Review:**
- **Multiple stakeholders** involved (3+ decision makers)
- **Cross-functional teams** requiring alignment
- **Significant budget or timeline** commitments
- **Regulatory or compliance** requirements
- **External dependencies** on other teams/systems
- **Customer-facing or revenue-critical** projects

**Stakeholder Categories:**
- **Business stakeholders** (Product owners, executives)
- **Technical stakeholders** (Architects, lead developers)
- **End users** (Customer representatives, user experience)
- **Operations** (Infrastructure, support, maintenance)
- **Compliance** (Legal, security, regulatory)

## Common Errors and Solutions

### ❌ Error Case 1: Vision documents not found
**Cause**: Vision review attempted before vision creation  
**Solution**: 
```bash
# Create project vision first
/create-vision
# Then proceed with review
/review-vision
```

### ❌ Error Case 2: Stakeholder misalignment detected
**Cause**: Different stakeholders have conflicting understanding of project goals  
**Solution**: 
- Facilitate alignment sessions with all stakeholders
- Clarify conflicting requirements and priorities
- Update vision document to address alignment gaps
- Re-run vision review to confirm consensus

### ❌ Error Case 3: Scope creep or unclear boundaries
**Cause**: Vision lacks clear scope definition or success criteria  
**Solution**: 
- Define explicit project boundaries and constraints
- Establish clear success metrics and acceptance criteria
- Document what is explicitly out of scope
- Ensure all stakeholders agree on scope limitations

## 📊 **VISION REVIEW QUALITY GATES**

### **🟢 APPROVED - Ready for Project Initiation**
- ✅ Clear and measurable business objectives
- ✅ Strong stakeholder understanding and agreement
- ✅ Realistic scope and constraint definition
- ✅ Technical feasibility validated
- ✅ Success criteria clearly defined
- ✅ All critical stakeholders committed

### **🟡 CONDITIONAL APPROVAL - Minor Alignment Issues**
- ⚠️ Minor stakeholder concerns that can be addressed
- ⚠️ Small scope adjustments recommended
- ⚠️ Communication plan enhancements needed
- ✅ Core vision and objectives solid
- ✅ No blocking alignment issues identified

### **🔴 REJECTED - Major Alignment Issues Require Resolution**
- ❌ Significant stakeholder disagreement on goals
- ❌ Unclear or unmeasurable success criteria
- ❌ Unrealistic scope or timeline expectations
- ❌ Technical feasibility concerns
- ❌ Insufficient stakeholder commitment
- 🔄 **Action**: Return to `/create-vision` for major revision

2. **Validate Vision Documents Exist**:
   ```bash
   # 📋 Validate that vision documents exist
   echo "📋 ビジョン文書分析中..."
   
   missing_docs=()
   vision_files=()
   
   # Check core vision document
   if [[ -f "docs/vision/project-vision.md" ]]; then
       vision_files+=("docs/vision/project-vision.md")
       echo "  📖 分析中: docs/vision/project-vision.md"
   else
       missing_docs+=("プロジェクトビジョン文書: docs/vision/project-vision.md")
   fi
   
   # Check steering documents
   steering_docs=("docs/steering/product.md" "docs/steering/tech.md" "docs/steering/structure.md")
   for doc in "${steering_docs[@]}"; do

       vision_files+=("docs/use_cases/core/index.md")
       echo "  📖 分析中: docs/use_cases/core/index.md"

   fi

       echo "❌ 以下のビジョン文書が見つかりません:"
   ```

3. **Business Alignment Analysis**:
   ```bash
   # 📊 Analyze business alignment and clarity
   echo "📊 ステークホルダー整合性確認中..."
   
   alignment_issues=()
   alignment_warnings=()
   
   # Check business objectives clarity
   vision_file="docs/vision/project-vision.md"
   if grep -q "目標\|目的\|objective\|goal" "$vision_file" 2>/dev/null; then
       echo "  ✅ ビジネス目標: 明確に定義済み"
   else
       alignment_issues+=("ビジネス目標の定義が不明確")
   fi
   
   # Check success criteria
   if grep -q "成功基準\|成功指標\|success criteria\|KPI\|メトリクス" "$vision_file" 2>/dev/null; then
       # Check if criteria are measurable
       if grep -qE "[0-9]+%|[0-9]+件|[0-9]+秒|[0-9]+円" "$vision_file" 2>/dev/null; then
           echo "  ✅ 成功基準: 測定可能な指標設定"
       else
           alignment_warnings+=("成功基準の定量化が不十分")
       fi
   else
       alignment_issues+=("成功基準が定義されていません")
   fi
   
   # Check scope boundaries
   if grep -q "スコープ\|範囲\|境界\|scope\|boundary" "$vision_file" 2>/dev/null; then
       echo "  ✅ スコープ境界: 適切に制限"
   else
       alignment_warnings+=("プロジェクトスコープの明確化が必要")
   fi
   
   # Check constraints
   if grep -q "制約\|限界\|constraint\|limitation" "$vision_file" 2>/dev/null; then
       echo "  ✅ 制約条件: 現実的な設定"
   else
       alignment_warnings+=("制約条件の明記が推奨")
   fi
   
   # Check value proposition
   if grep -q "価値\|メリット\|benefit\|value" "$vision_file" 2>/dev/null; then
       echo "  ✅ 価値提案: 定義済み"
   else
       alignment_issues+=("価値提案が不明確")
   fi
   
   # Report alignment status
   if [[ ${#alignment_issues[@]} -eq 0 ]]; then
       echo "  ✅ ビジネス整合性: 良好"
   else
       echo "  ❌ 整合性問題が検出されました:"
       printf '    ⚠️ %s\n' "${alignment_issues[@]}"
   fi
   
   if [[ ${#alignment_warnings[@]} -gt 0 ]]; then
       echo "  ⚠️ 整合性改善推奨事項:"
       printf '    💡 %s\n' "${alignment_warnings[@]}"
   fi
   ```

4. **Core Scenario Validation**:
   ```bash
   # 🎯 Validate core scenarios against business goals
   echo "🎯 コアシナリオ妥当性確認中..."
   
   scenario_issues=()

   core_scenarios_file="docs/use_cases/core/index.md"
   if [[ -f "$core_scenarios_file" ]]; then
       # Count core scenarios
       scenario_count=$(grep -c "^- \*\*" "$core_scenarios_file" 2>/dev/null || echo "0")
       
       if [[ $scenario_count -gt 0 ]]; then
           echo "  📊 コアシナリオ数: ${scenario_count}個"
           
           # Check business value mapping
           if grep -q "価値\|value\|benefit\|ROI" "$core_scenarios_file" 2>/dev/null; then
               echo "  ✅ ビジネス価値: 80%ルール適用"
           else
               scenario_warnings+=("ビジネス価値の明記が推奨")
           fi
           
           # Check user value
           if grep -q "ユーザー\|user\|顧客\|customer" "$core_scenarios_file" 2>/dev/null; then
               echo "  ✅ ユーザー価値: 明確に定義"
           else
               scenario_warnings+=("ユーザー価値の明確化が必要")
           fi
           
           # Check technical feasibility mentions
           if grep -q "技術\|technical\|実装\|implementation" "$core_scenarios_file" 2>/dev/null; then
               echo "  ✅ 技術実現性: 検証済み"
           else
               scenario_warnings+=("技術実現性の検証が推奨")
           fi
           
           # Validate scenario quality (rough heuristic)
           detailed_scenarios=$(grep -c "Given:\|When:\|Then:" "$core_scenarios_file" 2>/dev/null || echo "0")
           if [[ $detailed_scenarios -gt 0 ]]; then
               echo "  ✅ シナリオ詳細度: 適切"

           scenario_issues+=("コアシナリオが定義されていません")
       fi
   else
       scenario_issues+=("コアシナリオファイルが見つかりません")
   fi
   
   # Report scenario validation status
   if [[ ${#scenario_issues[@]} -eq 0 ]]; then
       echo "  ✅ コアシナリオ: 妥当"
   else
       echo "  ❌ シナリオ問題が検出されました:"

   fi
   
   if [[ ${#scenario_warnings[@]} -gt 0 ]]; then
       echo "  ⚠️ シナリオ改善推奨事項:"
   ```

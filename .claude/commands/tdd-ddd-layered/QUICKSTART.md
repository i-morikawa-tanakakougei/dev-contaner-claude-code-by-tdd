## 💡 **When Things Go Wrong (AI to the Rescue)**

### **Q: What if I get stuck?**
```bash
# Get AI diagnosis and next steps
/use-case-status 1

# Example AI response:
# "Current phase: Domain modeling"
# "Issue detected: Missing design documents"
# "Next step: Run /domain-modeling 1"
```

### **Q: What if AI rejects my work?**
```bash
# AI provides specific improvement guidance
/review-domain-design 1

# Example feedback:
# ❌ REJECTED - DDD violations detected:
#   - Direct entity references across aggregates
# 💡 Fix aggregate boundaries, then retry

# Follow AI guidance and rerun
```

### **Q: How to work with multiple issues?**
```bash
# Use comma separation for related features
/create-use-case 1,2,3 integrated-feature
/create-pr 1,2,3
```

- ❌ **REJECTED**: Critical issues, specific fixes provided
